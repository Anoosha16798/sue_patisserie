# Sue Patisserie

Premium home bakery site — 100% eggless, scratch-made custom cakes and artisanal desserts.

## Stack

- Next.js App Router + TypeScript (strict)
- Tailwind CSS v4
- Framer Motion

## Develop

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Routes

- `/` — landing, featured bento grid
- `/menu` — catalog with whipped cream vs buttercream pricing and item detail modal
- `/about` — home-bakery story
- `/contact` — inquiry form (`POST /api/inquiry`)

## Build

```bash
npm run build
npm start
```
